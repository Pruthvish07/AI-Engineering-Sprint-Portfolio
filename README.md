## 🛠️ Engineering Standards Followed
* **Modular Architecture:** Decoupled data ingestion, training pipelines, and inference scripts (`src/`).
* **Explainability First:** Every black-box model is paired with `SHAP` or `Grad-CAM` for transparent decision-making.
* **Reproducibility:** Locked dependencies and standardized project structures across all deliverables.
